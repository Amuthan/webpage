# Teaching
This page contains a list of courses I teach currently and have taught in the past. I have also provided links to lecture notes and other learning materials here. 

## Cal Poly

At Cal Poly, I teach the following courses related to aerospace structures. You can find catalog descriptions [here](https://catalog.calpoly.edu/courses/aero/).

- Aerospace Structural Analysis I (AERO 3331)
- Aersopace Structural Analysis II (AERO 4431)
- Aerospace Structural Dynamics Analysis (AERO 5534)
- Finite Element Analysis of Continua (AERO 5504)

I have also taught Aerospace Numerical Analysis (AERO 435), Finite Elements for Aerospace Structural Analysis (AERO 533), Continuum Mechanics (AERO 515) in the past. 

I regularly offer Special Problems for Undergraduates (AERO 2200/AERO 4400) every term to selected students on topics related to my research specialization---please talk to me if you are interested in learning more.

## Teaching Material

### Continuum Mechanics

These are older lecture notes on Continuum Mechanics. I'm no longer actively maintaining them, but I'm in the process of reworking them into a textbook. 

- [Mathematical prerequisites](https://amuthan.github.io/tensors-intro/): This webpage contains lecture notes providing an elementary introduction to essential topics in tensor algebra and analysis to get started with continuum mechanics.

- [Continuum Mechanics](https://amuthan.github.io/continuumMechanics/): This webpage is meant to provide a basic introduction to certain key ideas in continuum mechanics. *Note: I haven't had time to add the sections on solid mechanics yet!*

### Finite Element Analysis with scikit-fem

[scikit-fem tutorial](https://amuthan.github.io/tutorial-scikit-fem/): This is is a collection of tutorials on implementing the finite element method to solve partial differential equtions using [scikit-fem](https://scikit-fem.readthedocs.io/en/latest/index.html). This is a work in progress and will be updated in the future.
